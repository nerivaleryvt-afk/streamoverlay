Obtener el Twitch Client ID

Todo se saca desde el mismo sitio: twitchtokengenerator.com. Ahí generas el token y también te da el Client ID. No hace falta ir a ningún otro lado.

1 Abre el generador

Ve a https://twitchtokengenerator.com/ y pulsa Generate Token.

2 Inicia sesión con Twitch

Te pedirá iniciar sesión con tu cuenta. Acepta los permisos que muestra.

3 Elige Custom Scope Token

Cuando aparezcan las opciones, pulsa Custom Scope Token (no elijas Bot Chat Token, porque no te dejará banear ni crear encuestas).

4 Marca estos permisos

  • chat:read y chat:edit
  • channel:manage:broadcast
  • channel:manage:polls
  • channel:manage:predictions
  • moderator:manage:banned_users
  • user:read:emotes — para ver emotes nativos de Twitch

5 Copia tus datos

La página te mostrará dos cosas:

  • Client ID → pégalo en el campo correspondiente.
  • Access Token → pégalo en el campo Twitch Token (API).

Copia el Access Token, no el Refresh Token.

Generar el Twitch OAuth Token

Todo se saca desde el mismo sitio: twitchtokengenerator.com. Si ya generaste el Client ID ahí, esta vez solo necesitas copiar el Access Token.
Importante: debes elegir Custom Scope Token. Si eliges Bot Chat Token, no podrás banear ni crear encuestas.

1 Abre el generador

Ve a https://twitchtokengenerator.com/ y pulsa Generate Token. Inicia sesión con la cuenta correcta.

2 Elige el tipo correcto

Cuando aparezcan las opciones, pulsa Custom Scope Token.

3 Marca estos permisos

  • chat:read y chat:edit
  • channel:manage:broadcast
  • channel:manage:polls
  • channel:manage:predictions
  • moderator:manage:banned_users
  • user:read:emotes — para ver emotes nativos de Twitch

4 Copia tu Access Token

Copia el Access Token (empieza sin "oauth:") y pégalo en el campo Twitch Token (API).

No copies el Refresh Token ni el Client Secret. Solo el Access Token.

Obtener el canal de YouTube

No necesitas API Key ni OAuth. Solo el identificador del canal. Tienes tres formas, elige la que prefieras.

1 Forma fácil: el @handle

Abre tu canal en YouTube. En la barra de direcciones verás algo como:

https://www.youtube.com/@tucanal

Copia desde la @ hasta el final y pégalo en el campo.

Si no sabes cuál es tu @handle, ve a https://www.youtube.com/account y aparece ahí.

2 Forma estable: el Channel ID

El @handle puede cambiar, pero el Channel ID nunca cambia. Es más confiable.

Paso A: Abre tu canal en YouTube y pulsa F12 para abrir DevTools.

Paso B: Ve a la pestaña Console y pega esto:

document.querySelector('meta[itemprop="channelId"]').content

Paso C: Te devuelve algo como UCq0wtwcAmYtS3VUCgh1BWAg. Copia ese valor.

3 Forma rápida: la URL completa

También puedes pegar la URL completa del canal, el sistema la procesa igual:

https://www.youtube.com/@tucanal

4 ¿Varios canales?

Puedes añadir tantos como quieras con el botón Añadir otro canal de YouTube. Cada uno en su propia línea.

Obtener tu API Key de Groq

Groq es gratis y muy rápido. Tiene un límite diario muy generoso para responder al chat.

1 Crea una cuenta

Ve a https://console.groq.com/ y regístrate con Google o tu email.

2 Abre la sección de keys

Una vez dentro, en el menú lateral pulsa API Keys.

O ve directo a: https://console.groq.com/keys

3 Crea una nueva key

Pulsa el botón Create API Key. Ponle un nombre (ej: togi) y pulsa Submit.

4 Cópiala y pégala aquí

Te mostrará una key que empieza con gsk_. Cópiala.

Ojo: solo se muestra una vez. Si la pierdes, tendrás que crear otra.
